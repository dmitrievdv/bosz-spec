Задача: найти поток в полосе телескопа [TESS](https://tess.mit.edu/), используя спектр звезды из базы данных [BOSZ](https://archive.stsci.edu/hlsp/bosz). Для этого нужно определить несколько функций в файле `bosz-task.jl`. 

В файле `bosz-task.pdf` содержатся некоторые пояснения к задаче.

Для установки необходимых пакетов можно запустить интерпретатор `julia` в папке задания, перейти в нём в режим менеджера пакетов нажатием `]` и выполнить команды 
```julia
activate .
```
 и 
 ```julia
 update
```
После этого нужно выйти в стандартный режим интерпретатора нажатием `Backspace`

В файле `example.jl` содержатся простые примеры кода раюоты с массивами и чтения/записи файлов. Запустите этот код в интерпретаторе `julia` командой
```julia 
include("example.jl")
```

Однако, это только небольшие примеры. Для лучшего понимания языка и применяемых пакетов лучше ознамиться с документациями языка [julia](https://docs.julialang.org/en/v1/) и пакета [DataFrames](https://dataframes.juliadata.org/stable/)

После выполнения задания нужно запустить код в интерпретаторе: 
```julia 
include("bosz-task.jl")
```
